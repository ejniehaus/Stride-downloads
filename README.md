# Stride downloads

**Stride** is a Minecraft horse mod about horses with jobs. Instead of one generic horse, the world has 30 real breeds, from racing Thoroughbreds and endurance Arabians to Shire and Clydesdale draft horses, sturdy ponies and gaited breeds. Each breed has its own look, size and role. Natural horses are given a breed that suits their biome, and every breed has a spawn egg.

This repository holds release downloads only. It contains no source code.

## Requirements

- Minecraft **Java Edition 1.20.1**
- **NeoForge** for 1.20.1 (47.1 or newer)

## Install

1. Install NeoForge for Minecraft 1.20.1 from https://neoforged.net and run the game once with that profile.
2. Download `stride-<version>.jar` from the [latest release](https://github.com/ejniehaus/Stride-downloads/releases/latest).
3. Put the jar in your `.minecraft/mods` folder (`%APPDATA%\.minecraft\mods` on Windows, `~/Library/Application Support/minecraft/mods` on macOS).
4. Start Minecraft with the NeoForge 1.20.1 profile.

For a server, put the same jar in the server's `mods` folder. Server settings live in `serverconfig/stride-server.toml` inside each world.
